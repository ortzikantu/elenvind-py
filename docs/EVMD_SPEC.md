# EVMD 格式规范（Elenvind Markdown）

站点文章（`articles/`）与自定义页面（`usrpages/`）的内容格式，文件扩展名 **`.evmd`**。

实现代码位于 `elenvind/evmd_*.py`：

| 模块 | 职责 |
|---|---|
| `evmd_parser.py` | 块级解析与渲染主入口（`evmd_to_html` / `parse_document` / `document_meta`） |
| `evmd_header.py` | `@@@` TOML 文档头解析（`EvmdError`） |
| `evmd_inline.py` | 行内语法（转义 / code / 粗斜体 / 链接 / 脚注引用） |
| `evmd_directive.py` | 行级指令 `@{img}` / `@{video}` |

回归测试见 `tests/test_evmd_block.py`、`tests/test_evmd_inline.py`、
`tests/test_evmd_directive.py`、`tests/test_fuzz.py`；**任何语法改动都必须同步加测试**。

---

## 1. 文档结构

```
@@@                                   <- 文档头开始（必须是文件第一行）
title = "Article Title"
date  = 2024-01-01T10:00:00+08:00     <- 文档头内为 TOML 格式
authors = ["Alice"]
@@@                                   <- 文档头结束（独占一行）
（正文从这里开始）
```

- 文档头**可选**：自定义页面（如 `usrpages/about.evmd`）可以没有文档头，直接写正文；
  文章（`articles/`）必须带文档头，否则会被索引扫描跳过并记录错误日志。
- 文章头部常用字段（均可省略）：`title` / `date` / `lastmod` / `authors` / `source`。
- 标记 `@@@` 必须**独占一行**（前后不能有空格）；文档头以 `@@@` 开头却未闭合、
  或 TOML 写错时，文章会被跳过并记录错误日志。
- 换行符 CRLF / CR / LF 等价（`str.splitlines()` 语义），文件末尾有没有换行都可以；
  正文以 LF 归一化后交给块级引擎。

## 2. 正文语法

### 2.1 行内语法（用于段落、标题、列表项、引用、表格单元格内）

| 语法 | 效果 |
|---|---|
| `` `code` `` | `<code>` 行内代码（内容含 `$`、`*` 等一律原样） |
| `**bold**` | `<strong>` 加粗 |
| `*italic*` | `<em>` 斜体 |
| `_italic_` | `<em>` 斜体（仅两侧非字母/数字/下划线时生效，不破坏 URL 与单词内下划线） |
| `~~deleted~~` | `<del>` 删除线 |
| `@{link,url,text}` | 链接，如 `@{link,https://example.com,Example}` |
| `@{ref,id}` | 脚注引用（配合行级 `@{footnote,id,text}`，见 2.3） |
| `\X` | 转义：`\*`、`\_`、`\~`、`\&`、`\<` 等输出为字面字符，不触发格式 |

行内解析顺序（实现见 `evmd_inline.parse_inline`，顺序变化会影响兼容性）：

```
1. 清掉输入里的私有区字符（防伪造内部占位符）
2. 保护 `code` 跨度（内容原样，最后才转义输出）
3. 反斜杠转义 \X 暂存为占位符
4. 整体 HTML 转义（用户输入在此变成惰性文本）
5. 依次应用 **bold** -> *italic* -> @{link} -> _italic_ -> ~~del~~ -> @{ref}
6. 还原占位符（code 内容与转义字符在此重新转义后输出）
```

> 注意两点与 CommonMark 的**有意差异**：
> - 代码跨度优先于反斜杠转义：`\`` 不能"关掉"代码跨度（反斜杠会按字面输出）；
> - `***text***` 这类嵌套强调**不支持**（见第 3 节对照表），按普通文本处理。

### 2.2 块级语法

块级判定顺序（实现见 `evmd_parser._render_lines`，**顺序即优先级**）：

```
1. 围栏代码块 ```
2. 现代图片行 @{img,...}
3. 表格方言 @{table} + | 行 / 脚注定义 @{footnote,...} / 视频 @{video,...}
4. 缩进代码块（4 空格或 Tab，须在段落起点）
5. Setext 标题（===/---）与分隔线（---/***/___）
6. 空行（结束当前段落）
7. ATX 标题 #..######
8. 无序列表 / 有序列表 / 引用
9. 普通段落（缓冲，支持行尾硬换行）
```

| 语法 | 说明 |
|---|---|
| `#` ~ `######` 标题 | ATX 标题，`#` 后须有空格 |
| `Title` 下一行 `===` / `---` | Setext 标题（`===` 为一级，`---` 为二级；**须紧跟段落**） |
| `---` / `***` / `___` | 分隔线 `<hr>`（3 个以上，可与空格混排；**前面留空行**才表示分隔线，否则视为 Setext） |
| ````` ```lang ````` | 围栏代码块：内容整体转义；`lang` 经白名单校验后输出 `class="language-lang"` |
| 行首 4 空格 / Tab | 缩进代码块（须在空行之后开始） |
| `- item` / `* item` | 无序列表（连续行合并为一组） |
| `1. item` | 有序列表（连续行合并为一组） |
| `> quote` | 引用块（连续行合并，支持行内语法） |
| 行尾两空格 / 行尾 `\` | 段内硬换行 `<br>` |
| 空行 | 段落分隔 |
| `@{...}` 指令行 | 见 2.3 |

### 2.3 行级指令（方言核心）

**图片（v2 语法）：**

```
@{img, https://example.com/photo.png}         单张图：默认整行居中、按原始比例自适应
@{img, https://example.com/photo.png, 30%}    指定宽度百分比（5%~100%）

@{img, .../p1.png, 30%}    连续多行的百分比图自动收进同一个并排容器
@{img, .../p2.png, 30%}    见下方“同行判定”规则
@{img, .../p3.png, 30%}
```

**份额换算与同行判定（重要）：**

> NN% 是“含间隙的份额”，不是图片本身的像素宽度。同一行内各图的总视觉
> 宽度 = 份额之和；渲染时把图与图之间的间隙（`--img-gap`，见 style.css）
> 从行宽预算中扣除后，再按份额比例分配每张图的实际宽度：
>
>     实际宽_i = ( 份额和% − (N−1)×间隙 ) × 份额_i ÷ 份额和
>
> - 两张 50%：每张 = (100% − 1×间隙) ÷ 2 → 两张加间隙恰好占满整行，
>   **表现宽度与单张 100% 一致**（2 × 50% ≡ 1 × 100%）；
> - 三张 30%：每张 = (90% − 2×间隙) ÷ 3 → 整行视觉宽度为 90%（留白 10%）；
> - 份额和超过 100% 的行自动切开：例如 34% × 3 = 102% →
>   “2 张一行 + 1 张一行”，每行按上式换算且不足一行时居中；
> - 调整所有图片间距只需改 style.css 里 `.img-row` 的 `--img-gap`。

- 无百分比的图（`@{img,url}`）始终单独一行居中，不参与并排。
- 移动端（≤700px）由样式表以 `flex-basis: 100% !important` 覆盖换算结果，
  每张图自动改为纵向、独占一行。
- 历史版本的对齐/尺寸参数（`left`/`right`/`center`/`500px` 等）已整体移除，
  不再识别；含这些参数的行按普通段落原样显示。

**视频：**

```
@{video, https://example.com/movie.mp4}
```

**表格**（`@{table}` 起始行 + 后续以 `|` 开头的行）：

```
@{table}
| Name | Age |
| :--- | ---: |      <- 可选对齐行：:--- 左对齐 / ---: 右对齐 / :---: 居中
| Ada  | 36  |
| Bob  | 24  |
```

- 表头 + 至少一行数据（可省略对齐行）；单元格支持行内语法；
  列数按表头对齐，多余截断、不足留空；少于两行视为普通段落。

**脚注**：

```
正文引用@{ref,one}，行内即可。

@{footnote,one,脚注内容，支持**行内语法**与逗号。}
```

- 定义行 `@{footnote,id,text}` 独占一行（`id` 限 1-32 位字母/数字/`_`/`-`）；
- 编号按定义先后自动生成，文末统一输出脚注列表；
- 未定义的 `@{ref,id}` 不渲染；重复定义只保留第一处。

### 2.4 资源上限（防恶意输入）

文章文件本身有 1 MB 上限，解析器另设结构性上限（`evmd_parser` 顶部常量），
正常文章远达不到：

| 限制 | 值 | 说明 |
|---|---|---|
| 文档行数 | 50,000 | 超过抛 `EvmdError`（文章被跳过并记日志） |
| 表格行数 / 列数 | 500 / 64 | 超出部分忽略 |
| 脚注定义数 | 200 | 超出部分忽略 |
| 连续图片行 | 200/批 | 分批处理，内容不丢 |
| 单段行内文本 | 100,000 字符 | 超出则整段按纯文本转义输出 |
| 单行指令长度 | 2,048 字符 | 超长行不按指令识别 |

### 2.5 安全约定

- 原始 HTML 一律转义显示（防 XSS）；URL 仅允许 `http`/`https` 且必须有主机名，
  含控制字符/内部空白的 URL 直接拒绝；
- URL、代码内容、转义字符拼入 HTML 前均做转义，无法通过引号逃逸出属性；
- 输入中的 Unicode 私有区字符会被清理，无法伪造解析器内部占位符；
- `$` 无特殊含义，按普通字符输出（数学公式功能已整体移除）。

## 3. 语法支持对照（相对 CommonMark / GFM）

| 类别 | 语法 | 状态 |
|---|---|---|
| 基础 | 段落 / ATX 标题 / 围栏代码块 / 无序有序列表 / 引用 / 行内 code、粗斜体 | ✅ |
| 扩展写作 | 转义 `\X` / 硬换行 / 分隔线 / Setext 标题 / 删除线 / `_斜体_` / 代码语言 class / 缩进代码块 | ✅ |
| 方言 | `@{img}` `@{video}` `@{link}` `@{table}` `@{footnote}` `@{ref}` | ✅ |
| 刻意不支持 | 原始 HTML、`[text](url)`、`![img](url)`、尖括号/裸 URL 自动链接、危险协议、`$` 数学公式（已移除） | 安全设计 |
| 未实现 | 嵌套列表与嵌套引用、列表多行续行、GFM 表格（用 `@{table}` 替代）、任务列表、emoji 自动替换、`***` 嵌套强调、`` 多反引号代码跨度、`\`` 关闭代码跨度 | 后续可选 |

存量 `.md` 文件在 EVMD 重构中已原地迁移为 `.evmd`，内容未改动。
